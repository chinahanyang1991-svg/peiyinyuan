# 配音员 — 开发者文档

## 环境搭建

### 前提条件
- Python 3.10+
- Node.js 18+
- Redis 7+（可选）
- FFmpeg
- NVIDIA GPU + CUDA 12.1+（GPU 加速可选）

### 完整安装

```bash
# 克隆后进入项目目录
cd peiyinyuan

# 创建虚拟环境
python -m venv venv
source venv/bin/activate  # Linux/Mac
# venv\Scripts\activate   # Windows

# 安装后端（开发模式）
pip install -e ".[dev]"

# 安装前端
cd frontend
npm install

# 启动 Redis（Docker）
docker run -d -p 6379:6379 redis:7-alpine

# 启动 Celery Worker
celery -A backend.tasks.celery_app worker --loglevel=info

# 启动后端
uvicorn backend.main:app --reload --port 8000

# 启动前端
npm run dev
```

## 模块扩展

### 添加新 TTS 引擎

1. 在 `modules/tts_engine/engines/` 下创建新适配器，继承 `BaseTTSEngine`
2. 在 `engine_registry.py` 中注册
3. 在 `config.py` 中添加引擎配置项

### 添加新电子书格式

1. 在 `modules/book_parser/parsers/` 下创建新解析器
2. 实现 `parse(file_path) -> dict` 接口
3. 在 `parser_factory.py` 中添加文件扩展名映射

## 构建

### Docker 构建

```bash
# 构建并启动所有服务
cd docker
docker compose build
docker compose up -d

# 单独构建后端
docker build -f docker/Dockerfile.backend -t peiyinyuan-backend .

# 单独构建前端
docker build -f docker/Dockerfile.frontend -t peiyinyuan-frontend .
```
