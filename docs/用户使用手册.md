## 这份旧手册里被纠正掉的三条（留个记录，免得再被抄回去）

1. **不支持 CHM**。盘上 `modules/book_parser/parsers/` 只有 7 个解析器
   （epub / mobi / pdf / txt / md / html / docx），没有 CHM；AZW3 由 mobi 解析器一并处理。
   旧手册两处写"支持 CHM"是错的，硬上传会失败。
2. **旧手册完全没写怎么启动**。它第一步就是"点击左侧导航栏的导入按钮"，
   但读者此刻程序还没起来。现在《使用说明》第一节就是启动。
3. **格式与体积上限的口径**：单本最大 500MB、最多 200 万字，
   剩余磁盘不足 512MB 时拒绝导入（`backend/config.py`）。
   旧手册只说了 500MB。
